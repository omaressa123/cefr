# Learning Content Guide

## Add Vocabulary

Edit `backend/src/content/seedData.js` and add an item to `vocabulary` with a CEFR level, existing category slug, definition, Arabic translation, example, pronunciation representation, and metadata. Use a new category only after adding it to `categories`.

Run:

```bash
cd backend
npm run migrate
npm run seed:learning
```

The Docker startup command runs the schema migration. Run `npm run seed:learning` once after the API/database are available to load the foundational learning content.

The importer generates stable IDs from the level and word and updates an existing record when the content changes.

## Add Grammar

Add a record to `grammar` with a unique slug, level, explanation, Arabic explanation, examples, common mistakes, prerequisites, and related topics. Prerequisite and related values contain slugs, so keep them stable when content is edited.

## Add Pronunciation

Add a record to `pronunciation` with the sound, mouth and tongue guidance, voicing, example words, minimal pairs, common mistakes, and one or more exercises. Exercise types are `listen`, `repeat`, and `minimal_pair`. Audio is generated by the configured TTS adapter; do not add fake audio URLs.

## Add Sentence Exercises

Add a topic to `sentenceTopics` and include exercises with a supported type: `word_order`, `fill_blank`, `correction`, `transformation`, `completion`, or `multiple_choice`. Keep `answer` and `explanation` explicit so the API can check and teach the answer.

## Add Quiz Questions

Add a record to `quizQuestions` with one of the supported skills and a valid level. Options are returned to the client, while the correct answer is used only by the answer endpoint. Never put answer keys in a frontend component.

## Content Quality Rules

- Do not describe a word as officially CEFR-classified unless the source establishes that classification.
- Keep Arabic explanations and translations reviewed by a qualified speaker.
- Prefer concise examples that demonstrate the target structure.
- Include a common mistake when one is likely for learners.
- Use licensed or original content and record provenance when expanding the dataset.
- Keep IDs derived from stable slugs/keys so reseeding remains idempotent.
